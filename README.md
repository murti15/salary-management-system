# Salary Management System

A web-based salary management application for HR teams to manage employee records and understand salary distribution across countries.

## Problem Statement

ACME manages salary information for 10,000 employees across multiple countries using spreadsheets. This project aims to simplify employee salary management through a centralized web application.

## User Persona

- HR Manager

## Planned Features

- Employee directory with search and filters
- Server-side pagination
- Employee details and salary updates
- Dashboard with employee and salary summaries
- Support for multiple countries and currencies
- Seed script for 10,000 synthetic employees
- Automated tests

## Technology Stack

- Frontend: React
- Backend: Node.js and Express.js
- Database: SQLite
- Testing: Node.js test runner
